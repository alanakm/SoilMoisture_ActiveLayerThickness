# SoilMoisture_ActiveLayerThickness
This repository provides the scripts associated with the manuscript The Role of Soil Organic Layers and Soil Moisture on Active Layer Thickness in a Subarctic Permafrost Hillslope which uses the soilice model. 

The RunModelScripts folder contains the automated scripts used to run soilice. Soil parameters and boundary conditions are set within this function. 

The model outputs presented in the manuscript are available in ModelOutputs for all simulations, provided in .dill format. 

The dedcription of the soilice model can be found in the GitHub repository here: https://github.com/amireson/soilice
